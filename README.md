# opencode-spellcheck-v2

Проверка орфографии в реальном времени для **OpenCode 2** (TUI). Плагин следит за текстом в поле ввода, помечает орфографические ошибки и предлагает исправления. Встроенные словари **русского и английского** языков, умное игнорирование кода, путей, URL и идентификаторов.

> Это версия для **OpenCode 2** (`opencode v2.x`, API `@opencode/plugin/tui`). Для OpenCode 1 используйте первый репозиторий `opencode-spellcheck`.

---

## Возможности

- ✍️ **Проверка во время ввода.** Опрашивает активный редактор промпта и перепроверяет текст после задержки (по умолчанию 250 мс).
- ⏸️ **Только завершённые слова.** Слово проверяется после пробела, запятой, точки или другого разделителя — недопечатанное слово не подсвечивается.
- 🧠 **Настоящие словари.** Hunspell через `nspell` + `dictionary-ru` и `dictionary-en`. Слово считается правильным, если его знает хотя бы один словарь.
- 🚫 **Умное игнорирование кода.** Пропускает fenced/inline код, `@file` упоминания, `/команды`, `!shell` строки, URL, email, hex, числа и версии, идентификаторы (`camelCase`, `snake_case`, `ALLCAPS`), пути и имена файлов с расширениями кода/конфигов.
- 📖 **Словарь проекта.** Опция `extraWords` — слова, которые никогда не помечаются.
- 🔔 **Toast-уведомления.** Ошибки показываются с красной рамкой (`variant: "error"`).
- ⚡ **Быстрый режим.** `fastMode: true` отключает генерацию предложений — только пометка ошибок, работает заметно быстрее.
- 🛟 **Отказоустойчивость.** Если API TUI недоступен или словарь не загрузился, плагин не ломает интерфейс.
- 🧩 **Команда `/spellcheck`.** Явная проверка текста: `/spellcheck текст` или `/spellcheck` без аргументов (откроется диалог ввода).

## Установка

### 1. Сборка

```bash
git clone <этот-репозиторий> opencode-spellcheck-v2
cd opencode-spellcheck-v2
npm install
npm run build
```

`npm run build`:

1. **`embed`** — читает Hunspell `.aff`/`.dic` из `dictionary-ru` и `dictionary-en`, сжимает gzip, кодирует в base64 и записывает `src/generated/dict-data.ts`.
2. **`typecheck`** — проверяет типы.
3. **`bundle`** — esbuild собирает самодостаточные `dist/tui.mjs` и `dist/index.mjs`. Словари и `nspell` встроены, зависимостей во время выполнения нет.

### 2. Регистрация

Плагин можно подключить глобально или для проекта.

**Вариант A — `opencode.json(c)` (работает и для локального, и для удалённого сервера):**

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "/абсолютный/путь/opencode-spellcheck-v2",
      "options": {
        "debounceMs": 250,
        "minLength": 3,
        "fastMode": true,
        "showStatusLine": true,
        "extraWords": ["CAISO", "BESS"]
      }
    }
  ]
}
```

**Вариант B — `cli.json` (только терминал, остаётся активным при подключении к удалённому серверу):**

```jsonc
{
  "plugins": [
    {
      "package": "/абсолютный/путь/opencode-spellcheck-v2",
      "options": {
        "fastMode": true
      }
    }
  ]
}
```

> **Важно:** загрузчик OpenCode 2 ищет TUI-точку входа `tui.ts` **в корне пакета**, а не только в `exports`. В этом репозитории файл `tui.ts` уже есть — он реэкспортирует собранный `dist/tui.mjs`. Если переименовать или удалить его, плагин молча перестанет загружаться.

Глобальный конфиг: `~/.config/opencode/opencode.json(c)` и `~/.config/opencode/cli.json`. Конфиг проекта: `./opencode.json(c)` и `./.opencode/`.

Изменения конфигурации OpenCode 2 подхватывает без перезапуска. Если плагин не появился — выполните `/reload` или перезапустите TUI.

> Плагин также можно положить в `<проект>/.opencode/plugins/spellcheck/` (файлы `index.ts` и `tui.ts`) — OpenCode обнаружит его автоматически.

## Опции

| Опция | Тип | По умолчанию | Описание |
|---|---|---|---|
| `debounceMs` | number | `250` | Задержка после последнего изменения текста перед проверкой. |
| `minLength` | number | `3` | Игнорировать слова короче этого значения. |
| `extraWords` | string[] | `[]` | Всегда принимаемые слова (лексика проекта), без учёта регистра. |
| `showStatusLine` | boolean | `true` | Показывать ошибки через toast-уведомления. |
| `fastMode` | boolean | `false` | Не вычислять варианты исправлений — только помечать ошибки. |
| `toastDuration` | number | `6000` | Время показа toast в миллисекундах. |
| `debugLog` | boolean | `false` | Писать диагностику в `/tmp/opencode-spellcheck-v2.log`. |

## Как это работает в OpenCode 2

Документированный API TUI-плагинов OpenCode 2 не отдаёт текст промпта напрямую. Плагин использует публичный API OpenTUI: `context.renderer.currentFocusedEditor.plainText` — тот же редактор, который использует встроенный композер промпта.

- Текст опрашивается каждые 50 мс, проверка запускается после `debounceMs`.
- Проверяются только завершённые слова (за словом идёт разделитель).
- Toast не повторяется для той же ошибки, но появится снова, если исправить слово и ввести опечатку повторно.

Так как это опирается на внутренний редактор OpenTUI, в будущих версиях OpenCode поведение может измениться. В этом случае остаётся команда `/spellcheck`, которая не зависит от опроса редактора.

## Структура проекта

```
tui.ts                  корневой реэкспорт TUI-плагина (требование загрузчика OpenCode 2)
src/
  index.ts              серверная точка входа OpenCode 2 (заглушка для загрузки пакета)
  tui.ts                TUI-плагин: опрос редактора, toast, команда /spellcheck
  engine.ts             обёртка nspell: кэш, словари, ранжирование предложений
  tokenizer.ts          извлечение слов, пропуск кода/путей/URL/идентификаторов
  types.d.ts            ambient-типы для nspell и словарей
  generated/
    dict-data.ts        АВТО-СГЕНЕРИРОВАННЫЕ gzip+base64 словари
scripts/
  embed-dictionary.mjs  сжатие и встраивание словарей Hunspell
examples/
  opencode.json         пример конфигурации opencode.json
  cli.json              пример конфигурации cli.json
dist/
  tui.mjs               самодостаточный TUI-плагин
  index.mjs             серверная точка входа
```
